# Deployment Guide

## Quick Deploy Options

### Option 1: Render.com (Recommended - Backend + Database)

Render offers free tier with PostgreSQL + Python hosting.

#### Step 1: Create Render Account
1. Go to https://render.com
2. Sign up with GitHub
3. Connect your repository

#### Step 2: Deploy Database
1. Click "New +" → "PostgreSQL"
2. Name: `lenny-assistant-db`
3. Plan: Free
4. Click "Create Database"
5. **Important:** After creation, run this command in the database shell:
   ```sql
   CREATE EXTENSION IF NOT EXISTS vector;
   ```

#### Step 3: Deploy Backend
1. Click "New +" → "Web Service"
2. Connect your GitHub repo
3. Settings:
   - **Name:** lenny-assistant-api
   - **Root Directory:** `backend`
   - **Environment:** Python 3
   - **Build Command:** `pip install -r requirements.txt`
   - **Start Command:** `uvicorn app.main:app --host 0.0.0.0 --port $PORT`
   - **Plan:** Free

4. Add Environment Variables:
   ```
   DATABASE_URL=[Copy from your Render PostgreSQL internal connection string]
   ANTHROPIC_API_KEY=your_anthropic_key_here
   MODEL_PROVIDER=anthropic
   MODEL_NAME=claude-3-5-sonnet-20241022
   EMBEDDING_PROVIDER=local
   CORS_ORIGINS=*
   LOG_LEVEL=INFO
   ```

5. Click "Create Web Service"

#### Step 4: Initialize Database
Once deployed, go to the web service shell and run:
```bash
python scripts/ingest_transcripts.py
python scripts/generate_embeddings.py
```

### Option 2: Vercel (Frontend Only)

#### Step 1: Create Vercel Account
1. Go to https://vercel.com
2. Sign up with GitHub
3. Install Vercel CLI: `npm i -g vercel`

#### Step 2: Deploy Frontend
```bash
cd "The Lenny Growth Assistant"

# Update frontend/.env.production
echo "VITE_API_URL=https://your-backend-url.onrender.com" > frontend/.env.production

# Deploy
cd frontend
vercel --prod
```

#### Step 3: Update CORS
Go back to Render and update the backend's `CORS_ORIGINS` environment variable:
```
CORS_ORIGINS=https://your-frontend.vercel.app
```

## Option 3: Railway (All-in-One)

Railway offers the easiest deployment with free tier.

#### Step 1: Create Railway Account
1. Go to https://railway.app
2. Sign up with GitHub

#### Step 2: Deploy from GitHub
1. Click "New Project" → "Deploy from GitHub repo"
2. Select your repository
3. Railway will auto-detect docker-compose.yml

#### Step 3: Add Environment Variables
In Railway dashboard, add:
```
ANTHROPIC_API_KEY=your_key_here
MODEL_PROVIDER=anthropic
DATABASE_URL=[Auto-generated by Railway]
```

#### Step 4: Get Public URL
Railway will provide public URLs automatically.

## Option 4: Fly.io (Docker)

Perfect for Docker-based deployment.

#### Step 1: Install Fly CLI
```bash
brew install flyctl
fly auth signup
```

#### Step 2: Deploy
```bash
cd "The Lenny Growth Assistant"

# Create app
fly launch --no-deploy

# Set secrets
fly secrets set ANTHROPIC_API_KEY=your_key_here

# Deploy
fly deploy
```

## Manual Cloud Deployment (AWS/GCP/Azure)

### AWS Option

#### Backend (ECS + RDS)
1. Create RDS PostgreSQL instance
2. Install pgvector extension
3. Create ECS cluster
4. Deploy backend container
5. Set environment variables

#### Frontend (S3 + CloudFront)
1. Build: `cd frontend && npm run build`
2. Upload `dist/` to S3 bucket
3. Configure CloudFront distribution
4. Update DNS

### GCP Option

#### Backend (Cloud Run + Cloud SQL)
```bash
# Build and push
gcloud builds submit --tag gcr.io/YOUR_PROJECT/lenny-backend backend/

# Deploy
gcloud run deploy lenny-backend \
  --image gcr.io/YOUR_PROJECT/lenny-backend \
  --add-cloudsql-instances YOUR_INSTANCE \
  --set-env-vars DATABASE_URL=$DB_URL,ANTHROPIC_API_KEY=$KEY
```

#### Frontend (Firebase Hosting)
```bash
cd frontend
npm run build
firebase init
firebase deploy
```

## Troubleshooting

### Issue: pgvector not found
**Solution:** Run in database:
```sql
CREATE EXTENSION IF NOT EXISTS vector;
```

### Issue: CORS errors
**Solution:** Update backend CORS_ORIGINS to include frontend URL

### Issue: Database connection failed
**Solution:** Check DATABASE_URL format:
```
postgresql://user:password@host:5432/database?sslmode=require
```

### Issue: No data
**Solution:** Run initialization scripts:
```bash
python scripts/ingest_transcripts.py
python scripts/generate_embeddings.py
```
